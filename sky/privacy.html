⚡ 볼트윙 개인정보 처리방침

시행일 2026년 11월 13일 · 운영: motive(개인 개발자)

한 줄 요약
볼트윙은 이메일·실명·전화번호를 받지 않아요. 아이디·비밀번호·별명과 게임 기록만 서버에 두고, 광고·판매·마케팅에 쓰지 않아요. 아이디 없이 하면 기록은 내 기기에만 남아요.

1. 모으는 정보와 쓰는 곳

아이디·비밀번호로그인과 다른 기기에서 이어 하기. 비밀번호는 bcrypt로 바꿔 저장해서 운영자도 볼 수 없어요.
별명·조종사 레벨랭킹·친구 목록·대기실·귓속말에서 다른 사람에게 보여요.
게임 기록레벨, 고철, 기체·무기·부품, 클리어 기록 등. 로그인한 기기끼리 이어 하기.
랭킹 점수별명·점수·기체 이름과 무작위 기기 번호(이름과 연결되지 않음). 랭킹에서 빠질 수 있어요(🏆 랭킹 탭).
친구 정보무작위 친구 코드, 친구 관계·차단, 접속 여부. 로그인 아이디는 남에게 보이지 않아요.
귓속말받는 사람이 받아 가는 즉시 서버에서 지워요. 받아 가지 않아도 하루 뒤 지워요.
대기실 채팅서버에 저장하지 않아요. 그때 대기실에 있는 사람에게만 전해져요.
초대 기록누가 누구의 초대로 왔는지(보상을 한 번만 주려고).
신고·문의신고 대상의 별명·친구 코드와 최근 대화 몇 줄, 문의 내용. 운영자만 보고 180일 뒤 지워요.
내 기기 안게임 기록·설정·로그인 상태를 브라우저 저장소(localStorage)에 둬요. 서버로 가지 않아요.

모으지 않는 것: 이메일, 실명, 전화번호, 주소, 위치, 연락처, 사진, 결제 정보. 광고 추적 도구도 쓰지 않아요.

2. 보관 기간

  • 계정과 게임 기록: 계정을 지울 때까지. 지우면 친구·귓속말·초대 기록도 함께 지워져요.
  • 귓속말: 받아 가면 바로, 늦어도 하루 뒤 지움.
  • 신고·문의: 180일 뒤 지움.
  • 랭킹 점수: 주간·전체 순위를 보여 주는 동안 보관(이름 대신 별명과 기기 번호만).

3. 정보를 맡기는 곳

Supabase계정·기록·랭킹·친구·대기실 서버. 서버 위치는 대한민국 서울(AWS ap-northeast-2).
PeerJS 공개 중계친구와 함께 하기에서 두 기기를 처음 잇는 연결 안내만 해요. 게임 내용은 기기끼리 바로 오가요.
GitHub Pages게임 파일을 내려 주는 곳. 접속 기록(IP 등)은 GitHub 정책에 따라 처리돼요.

위 목적 외에 다른 사람·회사에 정보를 주거나 팔지 않아요.

4. 만 14세 미만

만 14세 미만은 보호자 동의 절차가 없어서 아이디를 만들 수 없어요. 아이디 없이 「혼자 하기」로 즐길 수 있고, 이때 기록은 그 기기에만 남아요. 만 14세 미만의 아이디가 만들어진 것을 알게 되면 지울 수 있어요.

5. 내 정보 보기·고치기·지우기

  • 별명 고치기: 격납고 맨 위 ✏️
  • 랭킹에서 빠지기: 🏆 랭킹 탭
  • 비밀번호 바꾸기·계정 지우기: ⚙️ 설정 → 계정
  • 이 기기의 기록 지우기: 로그아웃하거나 브라우저의 사이트 데이터 지우기

6. 지키는 방법

  • 게임은 서버 표를 직접 보지 못하고 정해진 함수로만 오가요. 남의 기록·대화를 읽을 수 없어요.
  • 비밀번호는 bcrypt로 바꿔 저장, 여러 번 틀리면 잠시 잠겨요.
  • 채팅·귓속말에서 연락처·SNS·주소 같은 말은 보내지 못하게 막아요.

7. 문의·신고

게임 안 ⚙️ 설정 → 🚨 신고·문의로 운영자에게 보낼 수 있어요. 귓속말 창과 대기실 채팅에도 🚨 신고 단추가 있어요.
